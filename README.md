# 🕵️ Discover Package Skills

An agent skill that provides guidance for how to find [skills](https://skills.sh/) and rules for LLMs/agents within npm
packages and add them to the current project.

This skill teaches agents to:

- **Discover** AI rules, prompts, agents, skills, and skill bundles exposed by project
  dependencies.
- **Integrate** those into the project’s existing rule/config files for whatever editors
  and tools the repo already uses.
- **Install reusable skills** via the [Skills](https://skills.sh/) package when it makes
  sense for the project.
